Guidance for Team Members

All team members should follow these instructions:

  1. Content: Add new destinations with clear titles, 1–2 sentence descriptions, and a matching image.
  2. Images: Use high-quality JPG/PNG images, sized around 800×600px, saved in the images/ folder with descriptive names.
  3. Categories: Tag every new entry with one of: beach, temple, or country so the search works.
  4. Code Style: Keep HTML/CSS/JS in their correct folders; use 2-space indentation and comment new code blocks.
  5. Testing: Before pushing, test locally with the Live Server, then refresh the GitHub Pages URL after deployment.
  6. Commits: Write clear commit messages (e.g., "Add Bali beach recommendation").
